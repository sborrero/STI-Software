# Televisión

Programas y simuladores Python para las prácticas de televisión del ciclo STI.

## Aplicaciones

En esta carpeta se publicarán herramientas para:

- Sistemas de televisión digital terrestre (TDT).
- Cálculos de parámetros de transmisión.
- Sistemas de antenas.
- Simulación de barrido de televisión.
- Análisis de señales de vídeo.
