
# Prácticas de Televisión

Programas y simuladores Python para el estudio de sistemas de televisión analógica y digital del ciclo STI.

## Aplicaciones disponibles

| Programa | Descripción |
|---|---|
| [Laboratorio de vídeo analógico](analog_video_lab_v5_5.py) | Análisis y experimentación con señales de vídeo analógico |
| [Simulador de barrido de televisión](barrido_television_v3_2.py) | Simulación del barrido y exploración de imagen |
| [Laboratorio de compresión digital](digital_video_lab_compresion_mod5_v1_3.py) | Estudio de los procesos de compresión de vídeo |
| [Laboratorio de crominancia](digital_video_lab_crominancia_v1_6.py) | Estudio de la información de color en vídeo digital |
| [Laboratorio de muestreo](digital_video_lab_muestreo_v1_4.py) | Muestreo y digitalización de señales de vídeo |

## Descarga y ejecución

1. Seleccionar el programa deseado.
2. Pulsar **Download raw file**.
3. Guardar el archivo `.py` en el ordenador.
4. Ejecutarlo utilizando el entorno Python de STI.
