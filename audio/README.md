# Audio

Programas y simuladores Python para las prácticas de audio del ciclo STI.

## Aplicaciones

En esta carpeta se publicarán herramientas para:

- Análisis de archivos de audio WAV.
- Muestreo y digitalización de señales.
- Codificación PCM.
- Comparación de señales digitales.
- Procesamiento y representación de señales de audio.
- Analizador de espectros de audio
