
# Prácticas de Audio

Programas y simuladores Python para las prácticas de audio del ciclo STI.

## Aplicaciones disponibles

| Programa | Descripción |
|---|---|
| [Generador de señales](audio_signal_generator.py) | Generación de señales de audio |
| [Analizador de espectro](audio_spectrum_analyzer_v2_5.py) | Análisis y representación espectral |
| [Comparador PCM](pcm_audio_comparator_v1_3.py) | Comparación de señales PCM |
| [Simulador ADC/DAC v1.8](simulador_adc_dac_v18.py) | Conversión analógico-digital y digital-analógica |
| [Simulador ADC/DAC v2.0](simulador_adc_dac_v2_0.py) | Versión actualizada del simulador ADC/DAC |

## Descarga y ejecución

1. Seleccionar el programa deseado.
2. Pulsar **Download raw file**.
3. Guardar el archivo en el ordenador.
4. Ejecutarlo utilizando el entorno Python de STI.
