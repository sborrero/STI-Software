# Prácticas de Audio

Programas y simuladores Python para estudiar señales de audio, su generación, digitalización y análisis.

## Aplicaciones disponibles

| Programa | Descripción |
|---|---|
| [Generador de señales](audio_signal_generator.py) | Generación de señales de audio para prácticas y experimentación. |
| [Analizador de espectro v2.5](audio_spectrum_analyzer_v2_5.py) | Análisis y representación del contenido espectral de señales de audio. |
| [Comparador PCM v1.3](pcm_audio_comparator_v1_3.py) | Comparación de señales PCM y estudio de los efectos de la digitalización. |
| [Simulador ADC/DAC v2.0](simulador_adc_dac_v2_0.py) | Simulación del proceso completo de conversión, incluyendo las etapas ADC y DAC y una tercera etapa de análisis del proceso. |

Se mantiene únicamente la versión **2.0** del simulador ADC/DAC como versión vigente. Esta integra el recorrido completo del proceso; no es una simple sustitución de la versión anterior, sino una versión ampliada.

## Descarga y ejecución

1. Abre el archivo del programa que quieras utilizar.
2. Pulsa **Download raw file** para descargarlo.
3. Guarda el archivo en tu equipo.
4. Consulta las bibliotecas que necesita el programa y ejecútalo con Python.
