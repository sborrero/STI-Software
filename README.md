
# STI-Software

Repositorio de programas y simuladores Python para las prácticas del ciclo formativo de Grado Superior de Sistemas de Telecomunicaciones e Informáticos (STI).

## Áreas de trabajo

| Área | Contenido |
|---|---|
| [Megafonía](megafonia/) | Diseño de instalaciones, cobertura y cálculo SPL |
| [Audio](audio/) | Muestreo, digitalización y procesado de audio |
| [Televisión](television/) | TDT, antenas y sistemas de vídeo |
| [Redes](redes/) | Cálculos y simulaciones de redes |
| [Telefonía](telefonia/) | Sistemas de telefonía y VoIP |

## Cómo utilizar los programas

1. Accede a la carpeta del área correspondiente.
2. Selecciona el programa Python que quieras utilizar.
3. Descarga el archivo `.py`.
4. Ejecuta el programa utilizando el entorno Python de STI.

## Requisitos

Los programas utilizan Python y las bibliotecas indicadas en las instrucciones de cada práctica.
